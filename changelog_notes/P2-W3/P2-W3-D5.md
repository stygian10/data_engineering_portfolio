### Problems Faced During Final Validation

The main issues encountered throughout P2-W3 were:

- Missing `weather-env` Kubernetes Secret.
- Airflow API server initially requiring database migration.
- AWS CLI init containers blocked by `imagePullPolicy: Never`.
- FastAPI replacement pod blocked by `Insufficient cpu`.
- Dashboard data initially becoming stale when S3 artifacts changed without a pod restart.
- Cloudflare permanent tunnel setup not being available with the current account configuration.

Each issue was investigated and resolved or deliberately deferred without leaving the core platform non-functional.

### Observations

The final validation demonstrated that the cloud deployment was more than a collection of independently running containers.

The complete chain was operational:

```text
Airflow
  -> W1-W10 pipeline
  -> AWS S3 artifacts
  -> Kubernetes application refresh
  -> FastAPI / Dashboard pod replacement
  -> S3 artifact download
  -> Updated prediction application
```

Kubernetes provided workload scheduling, service discovery, RBAC, persistent storage and controlled application lifecycle management.
